# Finance Data (Price & Dividends) downloader

The ticker price and dividend data are extracted from **Yahoo Finance**
by two small Python programs. The results are saved as text files (CSV
format) that you can feed into Claude, open in Excel etc

  -----------------------------------------------------------------------
  Program                             What it downloads
  ----------------------------------- -----------------------------------
  `fin_tickerprice.py`                Prices (Open, High, Low, Close, Adj
                                      Close, Volume)

  `fin_dividends.py`                  Dividends / distributions per unit,
                                      with ex-dividend dates
  -----------------------------------------------------------------------

You need an internet connection to use them.

## Start and end of the data

This applies to both programs.

- You choose only the **start month**.
- The **end is always today**, so you get everything from the 1st day of
  the start month up to the latest available date (the last trading day,
  for prices).
- You never need to type an end date.

## 1. Install Python (one time only)

1.  Go to <https://www.python.org/downloads/>.

2.  Click the yellow **Download Python** button and open the downloaded
    file.

3.  **Important:** on the first install screen, tick **Add python.exe to
    PATH** (at the bottom), then click **Install Now**.

4.  When it says *Setup was successful*, click **Close**.

5.  Check that it worked:

    1.  Press the Windows key, type `cmd` and press Enter. A black
        window (Command Prompt) opens.
    2.  Type `python --version` and press Enter. You should see
        something like `Python 3.12.1`.

6.  In the same black window, install the two add-ons the programs need.
    Type this, press Enter, and wait until it finishes:

        pip install pandas yfinance

## 2. Create a folder and copy the programs (one time only)

1.  Open File Explorer.
2.  Go to where you want the folder (for example, the
    `C:\Users\``<username>\`).
3.  Right-click an empty area, choose **New \> Folder**, and name it,
    for example `FinData`.
4.  Copy these two files into that folder:
    - `fin_tickerprice.py`
    - `fin_dividends.py`
5.  You do not need to create an `outputs` folder. The programs create
    it automatically the first time they run.

## 3. How to run a program

1.  Open the `Fin``Data` folder in File Explorer.
2.  Click in the address bar at the top (where the folder path is
    shown), type `cmd` and press Enter. A black window opens, already
    pointing at your folder.
3.  Type the command for the program you want (see below) and press
    Enter.
4.  Wait for the message that starts with `SUCCESS`. If you see a
    message starting with `Error`, read it. It says what to fix.

### Where do the results go?

- Both programs save their files in a folder called `outputs` inside the
  folder where the programs are kept (for example
  `C:\``Fin``Data\outputs`).
- If you run the same command again, the old file with the same name is
  **replaced** by the new one.
- Close the file in Excel first, or the program cannot replace it.

## Program 1: `fin_tickerprice.py` (prices)

**Purpose:** downloads the price history (Open, High, Low, Close, Adj
Close, Volume) from a start month up to the latest trading day.

**How to run:**

    python fin_tickerprice.py TICKER START_MONTH MODE

**Parameters** (all three are required, separated by spaces):

  -----------------------------------------------------------------------
  Parameter                           Meaning
  ----------------------------------- -----------------------------------
  `TICKER`                            The Yahoo Finance code or ISIN (see
                                      [About ticker
                                      names](#about-ticker-names)).

  `START_MONTH`                       The month to start from, written as
                                      Month-Year, for example `July-2019`
                                      or `Jul-2019`.

  `MODE`                              `daily` = one row for every trading
                                      day. `monthly` = one row per month,
                                      for the first trading day of each
                                      month.
  -----------------------------------------------------------------------

**Examples:**

    python fin_tickerprice.py NIFTYBEES.NS July-2019 monthly
    python fin_tickerprice.py GOLDBEES.NS Jan-2023 daily

**Output file** (in the `outputs` folder): `<TICKER>_<MODE>.txt`, for
example `NIFTYBEES.NS_monthly.txt`.

## Program 2: `fin_dividends.py` (dividends)

**Purpose:** downloads the dividends (distributions) paid per unit, with
the ex-dividend date, from a start month up to today.

**How to run:**

    python fin_dividends.py TICKER START_MONTH

**Parameters** (both are required, separated by a space):

  -----------------------------------------------------------------------
  Parameter                           Meaning
  ----------------------------------- -----------------------------------
  `TICKER`                            The Yahoo Finance code or ISIN (see
                                      [About ticker
                                      names](#about-ticker-names)).

  `START_MONTH`                       The month to start from, written as
                                      Month-Year, for example `July-2019`
                                      or `Jul-2019`. Dividends are
                                      included from the 1st day of this
                                      month.
  -----------------------------------------------------------------------

**Example:**

    python fin_dividends.py CLR.SI July-2019

**Output file** (in the `outputs` folder): `<TICKER>_dividends.txt`, for
example `CLR.SI_dividends.txt`.

## About ticker names

The ticker can be any of these:

  -----------------------------------------------------------------------
  Type                                Examples
  ----------------------------------- -----------------------------------
  Stock or ETF symbol                 `CLR.SI`, `NIFTYBEES.NS`

  Market index                        `^STI`, `^NSEI`

  Exchange rate                       `SGDINR=X`

  Fund ISIN code                      `INF879O01027` (Parag Parikh Flexi
                                      Cap Fund, Direct Growth, India)
                                      `SG9999002406` (LionGlobal
                                      Singapore Trust, SGD Acc, a
                                      Singapore unit trust)
  -----------------------------------------------------------------------

**Tip:** for the exact code of a stock, index or exchange rate, search
on [finance.yahoo.com](https://finance.yahoo.com) and copy the code
exactly as shown, including any dots, `^` or `=X`.

### How to find a fund's ISIN

An ISIN is a 12-character code (2 letters followed by 10 letters or
digits). To find it, do a Google search for the fund name plus the word
*ISIN*, for example:

    Parag Parikh Flexi Cap Fund Direct Growth ISIN

Fund factsheets and fund websites normally show the ISIN.

### If an ISIN gives "No data found"

Search for the fund on [finance.yahoo.com](https://finance.yahoo.com)
and use the code Yahoo shows for it instead. For example, LionGlobal
Singapore Trust SGD Acc is `0P00006G00.SI`.

## About the data

- **Prices (**`fin_tickerprice.py`**):** you choose how detailed the
  data is: `daily` (every trading day) or `monthly` (first trading day
  of each month).
- **Dividends (**`fin_dividends.py`**):** you choose only the start
  month. The program lists each dividend with its ex-dividend date, from
  that month up to today. Most funds and stocks pay dividends only a few
  times a year, so the list is usually much shorter than the price
  files.
- Exchange rates and most indices have no dividends, so
  `fin_dividends.py` shows an `Error: No dividend ... data found`
  message for them. That is normal.

## If something goes wrong

  ---------------------------------------------------------------------------------------
  Message                               What to do
  ------------------------------------- -------------------------------------------------
  `python is not recognized`            Python was installed without the "Add python.exe
                                        to PATH" tick. Run the installer again, choose
                                        **Modify/Repair**, and tick it.

  `No data found`                       The ticker code is wrong. Check it on
                                        [finance.yahoo.com](https://finance.yahoo.com).

  `Invalid start month format`          Write the month as `July-2019` or `Jul-2019`.

  `Cannot write ... file may be open`   Close the file in Excel and run the command
                                        again.
