--------------------------------------------------------------

The ticker price and dividend data are extracted from Yahoo Finance by
these two small Python programs, which save it as text files that you
can open in Excel.

   1. fin_tickerprice.py  - downloads PRICES
   2. fin_dividends.py    - downloads DIVIDENDS

You need an internet connection to use them.

START AND END OF THE DATA (applies to both programs)
   You choose only the START month. The END is always today, so you
   get everything from the 1st day of the start month up to the
   latest available date (the last trading day, for prices).
   You never need to type an end date.


--------------------------------------------------------------
 PART 1: INSTALL PYTHON (one time only)
--------------------------------------------------------------
1. Open your web browser and go to: https://www.python.org/downloads/
2. Click the yellow "Download Python" button and open the downloaded file.
3. IMPORTANT: On the first install screen, tick the box
   "Add python.exe to PATH" (at the bottom), then click "Install Now".
4. When it says "Setup was successful", click Close.
5. Check it worked:
   a. Press the Windows key, type  cmd  and press Enter.
      A black window (Command Prompt) opens.
   b. Type   python --version   and press Enter.
      You should see something like "Python 3.12.1".
6. Still in the black window, install the two add-ons the programs
   need. Type this and press Enter (wait until it finishes):

      pip install pandas yfinance


--------------------------------------------------------------
 PART 2: CREATE A FOLDER AND COPY THE PROGRAMS (one time only)
--------------------------------------------------------------
1. Open File Explorer.
2. Go to the place where you want the folder (for example, C:\ drive).
3. Right-click an empty area, choose New > Folder, and name it,
   for example:  StockData
4. Copy these two files into that folder:
      fin_tickerprice.py
      fin_dividends.py
5. You do not need to create an "outputs" folder. The programs create
   it automatically the first time they run.


--------------------------------------------------------------
 PART 3: HOW TO RUN A PROGRAM
--------------------------------------------------------------
1. Open the StockData folder in File Explorer.
2. Click in the address bar at the top (where the folder path is shown),
   type  cmd  and press Enter. A black window opens, already pointing
   at your folder.
3. Type the command for the program you want (see below) and press Enter.
4. Wait for the message that starts with "SUCCESS". If you see a
   message starting with "Error", read it - it says what to fix.

Where do the results go?
   Both programs save their files in a folder called "outputs"
   inside the folder where the programs are kept
   (for example C:\StockData\outputs).
   If you run the same command again, the old file with the same
   name is replaced by the new one. Close the file in Excel first,
   or the program cannot replace it.


--------------------------------------------------------------
 PROGRAM 1: fin_tickerprice.py  (PRICES)
--------------------------------------------------------------
PURPOSE
   Downloads the price history (Open, High, Low, Close, Adj Close,
   Volume) from a start month up to the latest trading day.

HOW TO RUN
   python fin_tickerprice.py  TICKER  START_MONTH  MODE

PARAMETERS (all three are required, separated by spaces)
   TICKER       The Yahoo Finance code or ISIN (see "About ticker
                names" below).
   START_MONTH  The month to start from, written as Month-Year,
                for example  July-2019  or  Jul-2019.
   MODE         Either  daily  or  monthly
                daily   = one row for every trading day.
                monthly = one row per month, for the first trading
                          day of each month.

EXAMPLES
   python fin_tickerprice.py NIFTYBEES.NS July-2019 monthly
   python fin_tickerprice.py GOLDBEES.NS Jan-2023 daily

OUTPUT FILE (in the "outputs" folder)
   <TICKER>_<MODE>.txt
   for example:  NIFTYBEES.NS_monthly.txt


--------------------------------------------------------------
 PROGRAM 2: fin_dividends.py  (DIVIDENDS)
--------------------------------------------------------------
PURPOSE
   Downloads the dividends (distributions) paid per unit, with the
   ex-dividend date, from a start month up to today.

HOW TO RUN
   python fin_dividends.py  TICKER  START_MONTH

PARAMETERS (both are required, separated by a space)
   TICKER       The Yahoo Finance code or ISIN (see "About ticker
                names" below).
   START_MONTH  The month to start from, written as Month-Year,
                for example  July-2019  or  Jul-2019.
                Dividends are included from the 1st day of this month.

EXAMPLE
   python fin_dividends.py CLR.SI July-2019

OUTPUT FILE (in the "outputs" folder)
   <TICKER>_dividends.txt
   for example:  CLR.SI_dividends.txt


--------------------------------------------------------------
 ABOUT TICKER NAMES
--------------------------------------------------------------
The ticker can be any of these:
   - a stock or ETF symbol      e.g.  CLR.SI    NIFTYBEES.NS
   - a market index             e.g.  ^STI      ^NSEI
   - an exchange rate           e.g.  SGDINR=X
   - a fund ISIN code           e.g.  INF879O01027
                                      (Parag Parikh Flexi Cap Fund,
                                       Direct Growth, India)
                                      SG9999002406
                                      (LionGlobal Singapore Trust,
                                       SGD Acc, a Singapore unit trust)

TIP: For the exact code of a stock, index or exchange rate, search on
finance.yahoo.com and copy the code exactly as shown, including any
dots, "^" or "=X".

HOW TO FIND A FUND'S ISIN
   An ISIN is a 12-character code (2 letters followed by 10 letters
   or digits). To find it, do a Google search for the fund name plus
   the word ISIN, for example:
      Parag Parikh Flexi Cap Fund Direct Growth ISIN
   Fund factsheets and fund websites normally show the ISIN.

IF AN ISIN GIVES "No data found"
   Search for the fund on finance.yahoo.com and use the code Yahoo
   shows for it instead (for example, LionGlobal Singapore Trust
   SGD Acc is 0P00006G00.SI).


--------------------------------------------------------------
 ABOUT THE DATA
--------------------------------------------------------------
PRICES (Program 1)
   You choose how detailed the data is: "daily" (every trading day)
   or "monthly" (first trading day of each month).

DIVIDENDS (Program 2)
   You choose only the start month. The program lists each dividend
   with its ex-dividend date, from that month up to today. Most funds
   and stocks pay dividends only a few times a year, so the list is
   usually much shorter than the price files.

   Exchange rates and most indices have no dividends, so Program 2
   will show an "Error: No dividend ... data found" message for them.
   That is normal.


--------------------------------------------------------------
 IF SOMETHING GOES WRONG
--------------------------------------------------------------
- "python is not recognized"  : Python was installed without the
  "Add python.exe to PATH" tick. Run the installer again, choose
  Modify/Repair, and tick it.
- "No data found"             : The ticker code is wrong. Check it on
  finance.yahoo.com.
- "Invalid start month format": Write the month as July-2019 or Jul-2019.
- "Cannot write ... file may be open": Close the file in Excel and
  run the command again.
